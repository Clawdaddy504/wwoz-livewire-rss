# WWOZ Livewire RSS

Unofficial RSS feed for the WWOZ Livewire Music Calendar.

Feed URL:

- `https://clawdaddy504.github.io/wwoz-livewire-rss/feed.xml`

JSON URL:

- `https://clawdaddy504.github.io/wwoz-livewire-rss/events.json`

The feed and JSON are regenerated by GitHub Actions on a schedule and committed into `docs/` for GitHub Pages hosting.
